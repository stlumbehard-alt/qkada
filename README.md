# ATLAS — Explorador Mundial

Site interativo em português para explorar países e regiões do planeta.

## Recursos
- Lista de países e territórios carregada da API REST Countries.
- Busca por país, capital, idioma e nome oficial.
- Filtros por continente e ordenação por população, área ou nome.
- Mapa interativo com marcadores clicáveis.
- Painel de detalhes com capital, população, área, idiomas, moedas, fuso horário, litoral, vizinhos e link para o Google Maps.
- Layout responsivo para computador e celular.

## Como executar
Abra `index.html` em um navegador com internet. A página usa Leaflet, mapas Carto/ OpenStreetMap e a API REST Countries, então esses recursos precisam de conexão.

## Publicar com GitHub Pages
1. Abra **Settings → Pages** no repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde a publicação.
